# 奇迹有名字 · 那个名字叫大连

一个大连英博 2026 赛季主题的球迷纪念网页，以积分曲线、赛季高光、图片图集、球迷故事和大连足球历史串起一份蓝色回忆。项目使用原生 HTML、CSS 和 JavaScript，附带 36 张本地 WebP 图片，无需注册、安装依赖或配置后端即可浏览。

**在线查看：** https://liufengyuan14.github.io/dalian-yingbo-2026-miracle/

## 使用说明

打开上面的链接，点击开场的“点击进入”，即可开始阅读；手机上也可以触摸进入。电脑端可用顶部导航跳转到数字、争冠曲线、高光时刻、收官之夜、球迷、历史和感谢等章节，手机端直接向下滑动浏览。查看积分曲线时，把鼠标移到图上，或在手机上触摸图表，可以查看每轮的积分与分差；较窄的屏幕可在图表区域横向滑动。点击支持放大的图片或卡片，可查看大图与说明，点击“×”、弹窗外侧或按 Esc 关闭。页面底部的“延伸阅读”可以展开文章地址，选中并复制后自行打开；该按钮不会自动跳转。

## 本地查看与维护

- 下载仓库或完整解压原包，保持 `index.html`、`app.js`、`critical/` 和 `assets/img/` 的相对目录结构不变。
- 使用现代浏览器打开 `index.html`；若本地打开受浏览器限制，可在项目目录启动静态服务器，例如 `python3 -m http.server 8000`，再访问 http://localhost:8000/。
- 页面需要启用 JavaScript 才能正常关闭开场遮罩并显示交互内容；没有背景音乐或账号登录功能。
- GitHub Pages 从 `main` 分支根目录发布。更新网页、脚本或图片后，等待自动部署完成，原分享链接仍可使用。仅上传 `index.html` 会导致图片和交互缺失，请同时保留资源文件。
